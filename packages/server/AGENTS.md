# Backend implementation

Backend code in this package must use a strongly object-oriented TypeScript design.
Before implementing, refactoring, or reviewing backend code, read and apply
[the backend-oop skill](../../.agents/skills/backend-oop/SKILL.md).

Keep the entry point thin, encapsulate behavior in cohesive classes, inject dependencies,
and keep class-specific helpers private. Apply the skill to the code being changed;
its presence alone does not request a rewrite of existing code.
