# Harness panel — wireframe

Status: **proposal**. Structure of the panel only: which regions exist, where
they sit, and what each screen is made of. No behavior, data or technology.

## 1. Regions

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ TOP BAR                                                                      │
├────┬─────────────────┬───────────────────────────────────┬───────────────────┤
│    │                 │ TABS                              │                   │
│ A  │                 ├───────────────────────────────────┤                   │
│ C  │                 │                                   │                   │
│ T  │   SIDE VIEW     │          MAIN AREA                │    CHAT PANEL     │
│ I  │                 │                                   │                   │
│ V  │                 │                                   │                   │
│ I  │                 ├───────────────────────────────────┤                   │
│ T  │                 │          BOTTOM PANEL             │                   │
│ Y  │                 │                                   │                   │
├────┴─────────────────┴───────────────────────────────────┴───────────────────┤
│ STATUS BAR                                                                   │
└──────────────────────────────────────────────────────────────────────────────┘
```

| Region | Purpose |
| --- | --- |
| Top bar | Current project, global actions |
| Activity bar | Switches what the side view shows |
| Side view | List or tree for the selected activity |
| Tabs | Open items in the main area |
| Main area | The opened item |
| Bottom panel | Secondary output for the main area |
| Chat panel | Conversation with the agent |
| Status bar | Small, always-visible state |

Side view, chat panel and bottom panel can be collapsed and resized.
